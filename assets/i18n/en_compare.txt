비교 => Compare
두 장을 나란히 봅니다: 보정 전·후 또는 다른 사진과. 단축키: C => Two pictures side by side: before and after, or beside another photo. Shortcut: C
비교 방식 => Comparison
보정 전·후 => Before / After
여러 이미지 => Two photos
좌우 => Side by side
상하 => Top and bottom
바꾸기 => Swap
두 사진의 자리를 서로 바꿉니다. => Swaps the places of the two pictures.
비교 닫기 => Close comparison
사진을 더블클릭해도 닫힙니다. => A double click on a picture closes it too.
비교할 다른 사진이 없어 보정 전·후로 표시합니다. => There is no other photo to compare with: showing before and after.
