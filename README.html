0.5.7 업데이트: 보정·원본 변경·백업 복원 뒤 오래된 썸네일을 화면에 보이는 사진부터 자동으로 갱신합니다. 원본이 없는 사진에는 오프라인 또는 원본 없음 · 이전 미리보기가 표시됩니다. 오프라인 편집용 미리보기가 있으면 새 보정도 반영합니다.

파일 관리 → 선택 사진 미리보기 다시 만들기로 선택한 사진을 일괄 갱신합니다. 하단 일괄 미리보기 중단으로 멈출 수 있으며, 이미 완료된 결과는 유지됩니다.

0.5.6 업데이트: 색상 → 카메라 프로파일 찾아보기에서 설치된 DCP 중 현재 카메라와 호환되는 프로파일을 검색하고 즐겨찾기에 넣습니다. Adobe 공용/사용자 폴더와 Luma의 camera-profiles 폴더를 찾으며 추가 폴더도 지정할 수 있습니다. 지원하지 않는 파일은 이유를 보여줍니다.

사진 관리 → RAW 가져오기 기본 보정에서 현재 보정이나 프리셋을 모든 RAW·카메라 모델·바디 일련번호별로 저장하세요. 바디→모델→전체 순서로 적용하며, 새로 가져오는 RAW의 썸네일부터 반영됩니다. 기존 사진은 그대로 유지합니다. 현재 사진에 저장된 항목 적용은 선택한 항목만 적용하며 실행 취소할 수 있습니다.

같은 카메라의 서로 다른 ISO 사진들을 선택하고 선택한 사진으로 ISO별 보정 만들기를 켜면 노이즈 제거·샤프닝·선명도·텍스처·안개 제거·검정값을 연결합니다. ISO 400/1600의 값이 0/10이면 ISO 800은 5입니다. 범위 밖에서는 끝값, ISO가 없으면 저장한 일반 값을 사용합니다. 일련번호는 표준 EXIF에서 읽은 경우에 제공됩니다. 크롭·마스크·복구·공간 변형은 기본값에 포함하지 않습니다.

0.5.5 업데이트: 색상 탭에서 RAW의 촬영 시·주광·직접 지정·스포이드 화이트밸런스와 DCP 카메라 프로파일을 사용합니다. 색온도·색조 조작마다 RAW를 다시 읽지 않습니다. 기존 사진은 현상 방식을 직접 바꾸기 전까지 이전 결과를 유지합니다.

3채널 RGB RAW, 일반 SDR 1개/2개/3개 광원 DCP와 사용자 지정 색도·스펙트럼 광원을 지원합니다. HDR·추가 RGB/공간 게인 테이블은 아직 지원하지 않습니다. Adobe 프로파일은 배포하지 않습니다. This product includes DNG technology under license by Adobe.

대량 라이브러리: 같은 1만 장 시험에서 목록 새로고침 약 6.4초→52ms, 보기 전환 약 6.9초→16ms.

Codex에 명령하기

상단 Codex 명령을 누르고 문장을 입력한 뒤 보내기 또는 Ctrl+Enter를 누릅니다. 예: “노출을 조금 올리고 하이라이트는 낮춰줘.” 응답의 숫자 보정 제안을 확인하고 이 보정을 사진에 적용을 누르면 사진에 반영됩니다. 실행 취소할 수 있습니다.

ChatGPT 연결에서 로그인한 계정과 제공 모델을 사용합니다. 텍스트와 선택한 숫자 보정값만 전송하며 사진 분석은 포함하지 않습니다. 대화는 앱을 닫으면 초기화됩니다. Codex CLI가 필요하고 계정 사용 한도가 적용됩니다.

  • 디테일·렌즈: 일반 노이즈 제거, 선명도 반경·디테일·마스킹, 텍스처·안개 제거, 수동 광학·원근. 4점 가이드는 왼쪽 위부터 시계 방향으로 지정합니다.

분류와 일괄 작업

상단에서 가져온 순서 / 파일 이름 / 촬영 시간 / 별점과 역순을 선택합니다. 정렬과 보기 전환에서도 다중 선택을 유지합니다. 검색·폴더 이동은 뒤에서 처리하며 새 조건을 입력하면 이전 검색 결과를 적용하지 않습니다.

가져오는 동안 하단 가져오기 중단을 누를 수 있습니다. 이미 추가한 사진은 유지하며, 같은 폴더를 다시 가져오면 중복 없이 이어서 처리합니다.

왼쪽 폴더·컬렉션으로 탐색하고 메뉴에서 스마트 컬렉션, 스택, 라벨, 필터, 가상 사본, 스냅샷, 비교·모아보기를 사용합니다. 보정 동기화에서 적용할 항목을 선택해 복사하거나 Auto Sync를 켭니다.

기존 사진의 카메라·렌즈 정보가 비어 있으면 EXIF 정보 다시 읽기를 실행하세요. 계층 키워드·촬영시각·GPS·XMP·프리셋을 관리할 수 있습니다. 부가 기능에는 GPS 지도, 감시 폴더가 있습니다.

파일과 출력

파일 관리 메뉴에서 이동·이름 변경, 누락 재연결, 중복 검사, 카탈로그 백업·복원을 제공합니다. 카탈로그 제거와 원본 휴지통 이동은 다른 작업입니다. 오프라인 편집은 원본이 있을 때 미리보기를 먼저 생성하세요.

JPEG·8/16비트 PNG·8/16비트 TIFF와 sRGB·Adobe RGB·Display P3·ProPhoto RGB 출력이 가능합니다. 이름 규칙 예: {stem}_{n:03d}. ProPhoto 작업 공간으로 광색역 입력을 보존할 수 있습니다. 모니터 ICC는 편집 화면·라이브러리·필름스트립·비교창에 적용합니다. 자동 모드는 창 이동 및 15초 주기로 프로파일을 확인하며, 프로파일이 없거나 손상되면 상태를 안내하고 sRGB로 표시합니다.

메타데이터 유지 옵션으로 촬영 정보·GPS·설명·키워드를 함께 저장할 수 있습니다. 원본 회전은 픽셀에 반영하고 방향 태그를 정상화합니다. 제조사 MakerNote, 4GB 이상 BigTIFF의 EXIF 출력, PNG PQ/HLG 색공간은 아직 지원하지 않습니다. 투명 입력은 흰색 배경으로 합성됩니다.

저장과 구현 범위

배포본의 새 카탈로그는 %LOCALAPPDATA%/Luma/Library, 소스 실행은 프로젝트의 data를 사용합니다. 설치할 때 기존 경로를 지정하면 그대로 이어서 사용합니다. 카탈로그 백업에는 사진 원본이 들어 있지 않습니다.

Adobe 현상 엔진·프로파일 데이터베이스와 같지는 않습니다. Lightroom 카탈로그의 지원 보정·이력·컬렉션을 이전하며 미지원 항목과 실제 작업 직접 대조는 남아 있습니다. 센서 RAW 화이트 밸런스와 CPU 현상 방식을 사용합니다. 렌즈 프로파일은 Lensfun 데이터를 사용하며 새 렌즈·촬영 조건은 빠져 있을 수 있습니다.
